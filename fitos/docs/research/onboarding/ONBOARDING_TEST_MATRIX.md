# Onboarding Test Matrix

## Automated Scenarios Required

| Scenario | Expected result |
| --- | --- |
| Beginner fat loss, low activity | Conservative deficit, beginner frequency, cardio baseline, high confidence only when required data exists |
| Intermediate muscle gain, 4 days, gym | Modest surplus, upper/lower or similar split, protein range rationale |
| Maintenance, not sure activity | Maintenance estimate range, lower confidence, assumption included |
| Endurance goal | Cardio-forward schedule, carbs-aware macro output, strength support |
| Custom workout split | Structured custom schedule, no generic string-only split |
| Manual calorie/macro targets safe | User override preserved, validated, explained |
| Manual calorie target unsafe | Activation blocked or safety warning produced |
| Pregnancy or breastfeeding | Clinician-aware flow, no aggressive target activation |
| Eating disorder risk | No calorie/macro prescription; escalation guidance |
| Profile edit after onboarding | New plan proposal generated; existing active plan remains until confirmed |
| Coach macro change action | Uses macro engine and plan proposal, not direct percentage split |
