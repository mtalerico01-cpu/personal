# Protein Guidelines

## Implementation Rules

- Adult RDA context: 0.8 g/kg/day (`SRC-NASEM-DRI-RDA-2005`). This is a baseline reference, not an optimized target for all exercising users.
- Exercising adults: generally 1.4-2.0 g/kg/day (`SRC-ISSN-PROTEIN-2017`).
- Hypocaloric resistance-trained users may justify higher protein ranges, such as 2.3-3.1 g/kg/day, with caution and context (`SRC-ISSN-PROTEIN-2017`).
- Protein recommendation should consider goal, current body mass, training status, energy deficit/surplus, dietary pattern, and user preference.
- Return confidence and rationale; do not simply add 10g because a user selected `high_protein`.
