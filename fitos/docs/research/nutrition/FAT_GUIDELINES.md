# Fat Guidelines

## Implementation Rules

- Adult AMDR context is 20-35% of energy (`SRC-NASEM-DRI-MACROS-2005`).
- Fat targets should respect minimum practical intake and user dietary pattern.
- Do not default all users to 25% fat.
- Keto or very-low-carbohydrate patterns should be explicit diet/macro choices with warnings and lower confidence when training performance is a priority.
