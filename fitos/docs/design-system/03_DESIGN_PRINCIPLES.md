# 03 - Design Principles

Date created: 2026-07-02

## 1. Clarity Before Decoration

Every visual decision must help the user understand where they are, what matters, what changed, and what action is available.

## 2. Intelligence Through Organization

Form Theory should feel smart because the right information appears at the right moment, not because the interface announces AI constantly.

## 3. Restraint Creates Confidence

Use lime, motion, shadows, imagery, and chart emphasis selectively. The brand becomes weaker when every element is loud.

## 4. Data Should Explain Itself

Metrics need context, comparison, time period, and meaning. A number without interpretation is incomplete.

## 5. Progressive Disclosure Preserves Power

Beginners should not be overwhelmed. Experts should not be constrained. The same interface should reveal more detail when context or preference calls for it.

## 6. One System Across Every Feature

Coach, Dashboard, Nutrition, Training, Cardio, Progress, Onboarding, and Profile should feel like one product with different tasks, not separate products.

## 7. Platform-Native, Brand-Consistent

iOS and Android should share Form Theory identity while respecting native behavior for back, sheets, keyboard, haptics, safe areas, controls, and accessibility.

## 8. Accessible By Default

Readable text, usable touch targets, chart alternatives, large text, screen-reader labels, reduced motion, and non-color indicators are design requirements, not QA leftovers.

## 9. Fitness-Focused Without Fitness Cliches

Avoid bro-science, aggression, guilt, hype, influencer language, and jargon-heavy interfaces. Form Theory is athletic and precise, not exclusionary.

## 10. Performance Is Product Quality

The design system must protect responsiveness. A premium interface that drops frames is not premium.
