# Form Theory Design System

Date started: 2026-07-02  
Gate: 1 - Discovery

This folder is the source of truth for the Form Theory design-system overhaul. Gate 1 is intentionally documentation-only: audit the current product, analyze the approved brand assets, research platform guidance, benchmark adjacent products, and define the system proposal before broad implementation.

## Authority Order

1. Approved Form Theory brand sheet and logo assets
2. Form Theory product principles
3. Official Apple, Android, Material, WCAG, React Native, and Expo guidance
4. Central design-system tokens
5. Shared component rules
6. Feature-specific needs with documented exceptions
