# FitOS

> AI-powered personal performance operating system

FitOS is not a calorie tracker. It is an intelligent coaching layer that synthesizes nutrition, training, recovery, and biometric data to give users the experience of having a personal coach available 24/7.

---

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | React Native + Expo |
| Language | TypeScript (strict) |
| Navigation | Expo Router (file-based) |
| Styling | NativeWind (Tailwind for RN) |
| State | Zustand |
| Server State | TanStack Query (React Query) |
| Database | Supabase (Postgres + Auth + Realtime) |
| AI | OpenAI API |
| Payments | RevenueCat |
| Health | Apple HealthKit |
| Animation | React Native Reanimated |
| Gestures | React Native Gesture Handler |
| Charts | Victory Native XL |
| Graphics | React Native SVG |

## Design Principles

- Dark mode first

- Inspired by: Apple Health, Apple Fitness, WHOOP, Linear
- No visual clutter
- Subtle, smooth animations
- Bold, readable typography
